## 📝 Decisões técnicas importantes
- Página única client-side (`page.tsx` "use client") — cardápio não precisa de SSR/DB nessa fase
- Cardápio como array em `lib/menu.ts` (sem backend) — YAGNI pra um portfólio
- Fotos via links diretos do Unsplash (sem API key, sem next/image) + `<FoodImage>` com fallback de marca
- Tema dark fixo (apetitoso, combina com a paleta vinho/laranja)

## ⚠️ Problemas encontrados e soluções
- Problema: `create-next-app` falhou (`EEXIST`/`EACCES` no `~/.npm/_cacache`)
  Solução: `npm install --cache "Desktop/Projetos AI/.npm-cache-vdt"`
- Problema: 3 fotos do Unsplash com assunto errado (Coca 2L=Pepsi, Limonada=bar, Nutella=yakisoba)
  Solução: Coca e Limonada trocadas por IDs conferidos no navegador; Nutella ficou com placeholder da marca
- Problema: Next 16 gera AGENTS.md/CLAUDE.md dentro do projeto
  Solução: `agentRules: false` no next.config.ts
- Problema: URL de produção feia (`cardapio-digital-five-cyan.vercel.app`)
  Solução: `vercel alias set` + `vercel.json` com `"alias": ["fornoebrasa.vercel.app"]`.
  Não deu pra renomear/recriar o projeto (comando destrutivo bloqueado). Pra tirar
  de vez a URL feia: renomear o projeto no dashboard da Vercel (Settings > General).
- Problema: Chrome no Mac não deixa a janela abaixo de ~500px pra testar 375px
  Solução: testado a 500px (todos os breakpoints mobile já ativos); pra 375px usar DevTools
